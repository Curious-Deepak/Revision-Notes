01 Computer Fundamentals

Computer

A computer is an electronic device that accepts data, processes it according to instructions, produces information and can store the result.

Input→Processing→Output→Storage

Data

Raw facts and figures.

Example: 50, 60, 70

Information

Processed and meaningful data.

Example: Average = 60

Remember: Data → Processing → Information.

02 Hardware & Software

Hardware

Physical components that can be touched.

Examples: keyboard, mouse, monitor, printer, CPU, hard disk.

Software

Programs/instructions that tell hardware what to do.

Examples: Windows, MS Word, Excel, Chrome, Linux.

TypeMeaningExamples
HardwarePhysical componentsKeyboard, monitor, printer
System softwareManages computer resourcesWindows, Linux
Application softwarePerforms user tasksWord, Excel, PowerPoint

OCR vs OMR vs MICR vs RFID

TechnologyFull FormWhat it doesMain use

Scanner vs OCR

Scanner: captures a document/image.

OCR: recognizes characters in that image and can convert them into editable text.

Barcode vs RFID

Barcode: optical scanning, usually needs line-of-sight.

RFID: radio waves; can identify tagged objects without direct line-of-sight.

Memory trick:
OCR = Characters
OMR = Marks
MICR = Magnetic/Cheques
RFID = Radio/Identification.

04 CPU & Processing

CPU — Central Processing Unit

Main processing unit that executes instructions and processes data.

ALU

Arithmetic + logical operations.

CU

Controls and coordinates operations.

Registers

Very fast temporary storage inside CPU.

RegisterMain function
PC — Program CounterAddress of next instruction
IR — Instruction RegisterCurrent instruction
MARMemory address being accessed
MDR/MBRData being transferred to/from memory
ACC — AccumulatorIntermediate arithmetic/logic results

Instruction Cycle

Fetch→Decode→Execute→Store / Write-back

Clock Speed & Cores

Clock speed: Hz, MHz, GHz. 3 GHz ≈ 3 billion cycles/second.

Cores: single, dual, quad, octa. Multiple cores help with parallel workloads.

Higher GHz alone does not determine total CPU performance.
PC vs IR :
 PC = next instruction address ; IR = current instruction.

05 Memory & Storage

Memory Hierarchy

Registers→Cache→RAM→Secondary Storage

Generally, speed decreases down the hierarchy.

Memory/StorageVolatile?Main purpose
RegistersYesImmediate CPU operations
CacheYesFrequently accessed data/instructions
RAMYesWorking memory
ROMNoFirmware/startup instructions
SSDNoPermanent storage
HDDNoPermanent storage

RAM

Volatile main memory. Stores currently used programs/data.

DRAM is common system RAM; SRAM is faster and commonly used for cache.

ROM

Non-volatile memory used for firmware/startup instructions.

PROM: programmable once | EPROM: UV erasable | EEPROM: electrically erasable/reprogrammable.

HDD vs SSD

HDDSSD
Magnetic platters, moving partsFlash memory, no moving mechanical parts
Generally slowerGenerally faster
Usually cheaper per GBUsually costlier per GB
Exam memory: RAM = working memory | ROM = firmware | SSD/HDD = permanent storage.

06 Operating Systems

Operating System

An OS is system software that manages hardware resources and provides services/interfaces for users and applications.

Examples: Windows, Linux, macOS, Android, iOS.

Process ManagementCreates/manages processes and allocates CPU time.
Memory ManagementAllocates/deallocates RAM and supports virtual memory.
File ManagementCreates, deletes, organizes and protects files.
I/O ManagementControls devices using drivers.
SecurityAuthentication, accounts, permissions.

Kernel

Core component of OS; manages CPU, memory, devices and system calls.

Kernel ≠ entire operating system.

GUI vs CLI

GUI: windows/icons/menus/pointer.

CLI: command-based interaction.

Important Terms

  • Multitasking: multiple tasks/processes managed/ executed concurrently.
  • Multiprocessing: multiple processors/cores used for processing.
  • Process: program currently executing.
  • Program: stored set of instructions.
  • Booting: starting/restarting and loading the OS.
  • Cold boot: start from powered-off state.
  • Warm boot: restart a running system.
  • Device driver: software enabling OS-hardware communication.
  • Virtual memory: secondary storage used to extend apparent memory; slower than RAM.

08 Internet

Internet

Global network of interconnected networks.

WWW (World Wide Web)

Web service consisting of interconnected web pages/resources that operates over the Internet.

TermExam-oriented meaning
BrowserApplication to access/display web pages; Chrome, Edge, Firefox.
Search EngineSearches/indexes web information; Google, Bing.
URL (Uniform Resource Locator)Uniform Resource Locator; address/location of a resource.
IP AddressLogical address of device/ interface.
DNS (Domain Name System) Resolves domain names to IP addresses.
ISP (Internet Service Provider)Provides connectivity.
HTTP (Hypertext Transfer Protocol)Web communication protocol.
HTTPS (Hypertext Transfer Protocol Secure)HTTP secured with TLS for data in transit.

IPv4 vs IPv6 : They are used to uniquely identify devices on a network so they can find, communicate, and route data to each other across the internet.

IPv4: 32-bit addresses.

IPv6: 128-bit addresses.

Upload vs Download

Download: Internet/ server → device.

Upload: device → server.

Email

CC: visible additional recipients.

BCC: addresses generally hidden from other recipients.

Cookies vs Cache

Cookies: session/preferences/tracking-related website data.

Cache: locally stores web resources to speed loading.

Cloud Computing

Computing resources/services delivered over a network, commonly the Internet. Examples: cloud storage, cloud servers, online applications.

DNS vs DHCP: DNS = domain name resolution; DHCP = automatic network configuration such as IP address, subnet mask and gateway.

Superscript vs Subscript

Superscript = above baseline, e.g. x².

Subscript = below baseline, e.g. H₂O.

Text vs Paragraph Formatting

Text: font, size, bold, italic, color.

Paragraph: alignment, indentation, spacing, bullets/numbering.

Indentation

Left: inward from left margin.

Right: inward from right margin.

First-line: only first line moves.

Hanging: first line stays at margin; subsequent lines move inward.

Bullets vs Numbering

Bullets: unordered list.

Numbering: ordered/sequential list.

12 Page Setup & Document Layout

Margins

Margins are the blank spaces between the page edges and the document content.

Top, bottom, left and right margins.

Margin ≠ indentation. Margin is page-level blank space; indentation moves paragraph text relative to the margins.

Orientation

Portrait: vertical.

Landscape: horizontal.

Paper Size

Common sizes: A4, Letter, Legal. A4 is commonly used for documents in India.

Page Break vs Section Break

Page Break: starts following content on a new page. Ctrl + Enter.

Section Break: divides a document into sections allowing different formatting/layout.

Header

Top area of a page.

Footer

Bottom area of a page.

Watermark

Text/image behind the main content, e.g. DRAFT or CONFIDENTIAL.

15 Printing & Document Views

Print

Ctrl + P opens printing options. You can select printer, copies and pages.

Print Preview: see document appearance before printing.

Collated vs Uncollated

Used mainly when printing multiple copies of a multi-page document.

Collated

Complete copies in order.

3 pages × 2 copies: 1,2,3 | 1,2,3

Uncollated

Same pages grouped.

3 pages × 2 copies: 1,1 | 2,2 | 3,3

These are printing-order options. They do not by themselves mean creating multiple PDF files.

Top Exam Traps

  • PC = next instruction address; IR = current instruction.
  • DNS resolves names; DHCP provides network configuration.
  • OCR reads characters; OMR detects marks.
  • MICR is used for magnetic characters, especially bank cheques.
  • RFID uses radio waves for contactless identification.
  • Scanner captures an image; OCR recognizes text in it.
  • Hub broadcasts; Switch uses MAC; Router routes using IP.
  • Internet ≠ WWW.
  • Margin = blank space around page content; indentation changes paragraph position.
  • Collated = complete sets; Uncollated = same pages grouped during printing.
  • Zoom changes screen magnification, not actual font/print size.
